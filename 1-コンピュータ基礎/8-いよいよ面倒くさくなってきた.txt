　前章で説明した足し算の回路は half adder、日本語だと「半加算器」と呼ばれる。
「半」なのは繰り上がりの足し合わせを考慮していないからだ。
では、繰り上がりの足し合わせを考慮するとどうなるだろうか。
前章の4パターンに繰り上がりの有無が加わるので、パターンとしては全部で8パターンになる。
0 + 0 + 0 = 0
0 + 1 + 0 = 1
1 + 0 + 0 = 1
1 + 1 + 0 = 10
0 + 0 + 1 = 1
0 + 1 + 1 = 10
1 + 0 + 1 = 10
1 + 1 + 1 = 11
　1桁の計算結果部分については、半加算器の1桁の計算結果部分に繰り上がり分を足し合わせれば良さそうだ。要は、半加算器を二つ組み合わせればいい。
　では繰り上がり部分はどうだろう。最初の半加算器の繰り上がり部分、二段目の半加算器の繰り上がり部分、想定される結果をOFF/ONに置き換えて並べてみよう。
OFF : OFF : OFF
OFF : OFF : OFF
OFF : OFF : OFF
ON : OFF : ON
OFF : OFF : OFF
OFF : ON : ON
OFF : ON : ON
ON : ON : ON
　どちらか一方がONならばON、要するにスイッチが並列に並んだ回路だ。
　この回路で計算された繰り上がりを次の桁の繰り上がりに繋ぐことで、多桁の足し算にもたいおうできるようになる。
この回路を full adder、日本語だと「全加算器」と呼ぶ。
　足し算が電気回路でできるということは、四則演算すべてが電気回路で可能になるということだ。
これが「電子計算機」たるコンピュータの基礎になっている部分だ。
